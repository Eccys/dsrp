# DSRP - Student Academic Success

This is my DSRP project for summer 2026. I'm looking at what factors relate to university students dropping out, staying enrolled, or graduating.

Dataset is from UCI (Predict Students' Dropout and Academic Success). About 4400 students and 37 columns. Stuff like grades, attendance, scholarships, age, etc.

I'll put cleaning, analysis, and notes in this repo as I go.
